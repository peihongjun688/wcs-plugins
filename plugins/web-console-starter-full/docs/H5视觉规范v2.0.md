# H5 视觉规范 v2.0（Mobile Visual Spec v2.0）

> web-console-starter · 手机 H5 视觉层的**具体规格**。参考基线：EPDM 运维监控中心 H5（深色玻璃风 + 底部 tabbar + 彩色品牌图标 + 大字数字节奏）。本规范与 `H5移动端开发约束与指导.md`（适配层）配合使用：前者讲"长什么样"，后者讲"在哪些尺寸下怎么变"。
> 配套阅读：`docs/设计规范.md`（桌面 token 契约，H5 **不新增桌面 token、不改颜色体系**）、`frontend/src/style.base.css`（移动端全局样式实现位）、`frontend/src/layout/Layout.vue`（TabBar 与抽屉实现位）。

---

## 1. 设计原则

1. **深色玻璃为主色系**：默认 4 套深色玻璃风皮肤（深蓝/墨绿/紫金/冰蓝），附加 2 套浅色变奏以满足不同业务调性。
2. **移动优先**：基准设计稿 375×812，向下兼容 320，向上到 768（768 以下强制启用 TabBar + 抽屉降级模式）。
3. **物理拟真**：高斯模糊 + 半透 + 微高光 + 微阴影；卡片有"漂浮感"。
4. **数字节奏**：大数字 + 小单位，紧凑精致；标题小、单位更小。
5. **图标按业务上色**：业务图标默认带 5 色变奏（青/紫/红/橙/绿），按业务语义自动选用。

---

## 2. 断点体系（沿用 v1.0，本规范不新增断点）

| 断点 | 形态 | 布局 |
|---|---|---|
| `> 1100px` | 桌面宽屏 | 侧栏 220px + 内容多列 |
| `769px ~ 1100px` | 桌面窄窗 / 平板横屏 | 侧栏保留，内容 1~2 列 |
| `≤ 768px` | **手机 H5 / 平板竖屏** | **底部 TabBar 强制默认**；抽屉降级为"全部模块"二级入口；内容单列 |

实现位置：`Layout.vue` 用 `window.matchMedia('(max-width: 768px)')` 驱动 `isMobile`；H5 段路由渲染 `<MobileTabBar/>` 与"全部模块"抽屉按钮。

## 3. 颜色系统（6 套皮肤，全部走 token 契约）

**token 命名规范**（CSS 变量，挂 `:root[data-skin="xxx"]` 上）：
- `--app-primary`：主色（按钮、强调、TabBar 选中态）
- `--app-accent-1` ~ `--app-accent-5`：5 色强调色（青/紫/红/橙/绿），按业务语义分配
- `--app-bg-deep`：深色背景（页面底色，深色皮肤用）
- `--app-glass-bg`：玻璃卡背景（半透明 + backdrop-filter）
- `--app-glass-border`：玻璃卡边框
- `--app-text-1`：主文（90%）
- `--app-text-2`：次文（70%）
- `--app-text-3`：弱文（45%，数字单位、标签）
- `--app-success / --app-warning / --app-danger`：状态色

### 3.2 2 套浅色

| 皮肤名 | slug | 主色 | 强调色 1-5 | 玻璃底色 | 适用场景 |

### 3.3 业务图标配色规则

9 宫格模块图标按业务语义自动选 `--app-accent-N`：
- **实时监测 / CPU / 内存**：青（accent-1 / 蓝青）
- **历史趋势 / 报表 / 分析**：紫（accent-2）
- **告警 / 严重 / 故障**：红（accent-3）
- **运维执行 / 操作类**：橙（accent-4）
- **健康/巡检 / 通过 / 成功**：绿（accent-5）

## 4. 字号阶梯

| 用途 | 大小 | 字重 | 应用 |
|---|---|---|---|
| display | 28px | 700 | 健康度大数字、关键指标大字 |
| h1 | 22px | 700 | 页面大标题 |
| h2 | 18px | 600 | 区块标题、卡片标题 |
| body | 14px | 400 | 正文 |
| small | 12px | 400 | 次要文字、标签 |
| tiny | 11px | 400 | 数字单位、徽章、描述 |

**数字节奏**：数字 22-28px / 700 + 单位 11-12px / 400 / `--app-text-3`，两者同行布局，单位紧贴数字。

## 5. 间距（4 倍数体系）

| token | 值 | 应用 |
|---|---|---|
| sp-1 | 4px | 图标与文字间距 |
| sp-2 | 8px | 紧凑内边距 |
| sp-3 | 12px | 卡片内边距、卡间距 |
| sp-4 | 16px | 区块内边距、页面左右 padding |
| sp-5 | 20px | 区块间距 |
| sp-6 | 24px | 大区块间距 |

**H5 页面左右 padding**：16px；卡片内边距：16px；卡片间距：12px。

## 6. 圆角

| token | 值 | 应用 |
|---|---|---|
| r-xs | 4px | 小标签、徽章 |
| r-sm | 8px | 小按钮、小标签 |
| r-md | 12px | **标准卡片、按钮**（H5 主体） |

## 7. 阴影

| 名称 | 值 | 应用 |
|---|---|---|
| shadow-card | `0 4px 16px rgba(0,0,0,.15)` | 浅卡（浅色皮肤） |
| shadow-glass | `0 8px 32px rgba(0,0,0,.25), inset 0 1px 0 rgba(255,255,255,.08)` | **玻璃卡**（深色皮肤） |
| shadow-hover | `0 6px 24px rgba(0,0,0,.28)` | 卡 hover |
| shadow-tabbar | `0 -4px 16px rgba(0,0,0,.15)` | TabBar 顶部投影 |

## 8. 玻璃效果参数（深色皮肤标配）

```css
.glass {
  background: var(--app-glass-bg);
  backdrop-filter: blur(20px) saturate(180%);
  -webkit-backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid var(--app-glass-border);
  box-shadow: var(--shadow-glass);
  border-radius: var(--r-md);
}
```

**微高光**：深色玻璃卡顶部 1px `inset 0 1px 0 rgba(255,255,255,.08)`；浅色玻璃卡顶部 `inset 0 1px 0 rgba(255,255,255,.5)`。

## 9. 底部 TabBar（H5 主导航，强制默认）

| 项 | 规格 |
|---|---|
| 高度 | 56px（不含安全区） |
| 背景 | `var(--app-glass-bg)` + `backdrop-filter: blur(20px) saturate(180%)` |
| 顶部边框 | 1px `var(--app-glass-border)` + `box-shadow: var(--shadow-tabbar)` |
| 安全区 | `padding-bottom: env(safe-area-inset-bottom)`（iPhone X+ 适配） |
| 项数 | **5 项固定**：`总览` / `告警` / `全部` / `趋势` / `我的` |
| 单项布局 | 图标（24×24 SVG）+ 文字（11px）垂直堆叠 |
| 选中态 | 图标 + 文字同色 `--app-primary`，文字 600 |
| 未选中态 | `--app-text-3` |
| 红点徽章 | 右上角 8×8 圆点 `var(--app-danger)`（告警项） |
| 中间"全部" | 可加大 56×56 圆形凸起作为视觉锚点（参考 EPDM） |

**TabBar 路由**：
- `总览` → `/dashboard`
- `告警` → `/alerts`（H5 专属，未实现则跳转 `/dashboard`）
- `全部` → `/modules`（H5 专属，9 宫格模块入口；或唤出抽屉菜单）
- `趋势` → `/trend`
- `我的` → `/me`（H5 专属，个人中心；或跳转 `/settings`）

## 10. 抽屉菜单（降级为"全部模块"二级入口）

**仅在 Dashboard / 列表页顶部"九宫格"图标按钮唤出**；不在全局 TabBar 出现。

| 项 | 规格 |
|---|---|
| 方向 | ltr 左滑 |
| 宽度 | 屏幕 80%（375 屏约 300px） |
| 背景 | `var(--app-bg-deep)` + 玻璃效果 |
| 项布局 | 图标（20×20，--app-accent-N）+ 标题（14px / 600）+ 描述（11px / 400 / --app-text-3） |
| 项高 | 56px |
| 选中态 | 背景 `rgba(255,255,255,.05)` + 左侧 2px `var(--app-primary)` |
| 关闭 | 点菜单项自动跳转并收起；点击遮罩关闭 |

## 11. 业务图标库（30+ 内联彩色 SVG）

`frontend/src/icons/svg/` 下存放 SVG 文件，按业务域分目录。每个图标文件**仅声明 path**，颜色由父元素 `currentColor` 或 CSS 变量 `--app-accent-N` 驱动（5 色变奏 = 5 个 CSS 变量切换）。

| 业务域 | 图标 | accent 映射 |
|---|---|---|
| 监测 | 实时监测/历史趋势/告警中心 | 监测→accent-1，趋势→accent-2，告警→accent-3 |
| 数据 | SQL 性能/Archive/网络传输 | SQL→accent-1，Archive→accent-1，网络→accent-2 |
| 系统 | 磁盘 IO/故障日志/巡检报告 | IO→accent-1，日志→accent-2，巡检→accent-5 |
| 管理 | 运维执行/系统设置 | 执行→accent-4，设置→accent-1 |
| 数据可视化 | 报表/列表/明细/看板/分析 | 报表→accent-2，列表→accent-1，明细→accent-5，看板→accent-2，分析→accent-2 |
| 通用 | 刷新/收藏/分享/通知/用户/关于/九宫格/勾选/搜索/锁定/标签/缩放 | 默认 accent-1 |

**图标尺寸规范**：默认 24×24 viewBox；模块卡内 32×32（带圆角背景 40×40）；TabBar 内 24×24；抽屉内 20×20。

## 12. 核心组件规范

### 12.1 ModuleGrid（9 宫格模块卡）

| 项 | 规格 |

| 描述 | 11px / 400 / --app-text-3（可选） |
| 红点徽章 | 右上角 8×8 圆点（可选） |

### 12.2 HealthRing（健康度圆环）

| 项 | 规格 |
|---|---|
| 大小 | 96×96（桌面 120×120） |
| 圆环 | stroke 8，背景 `rgba(255,255,255,.08)`，进度色按分数色阶 |
| 分数色阶 | ≥80 绿 / 60-79 橙 / <60 红 |
| 中心数字 | 28px / 700 |
| 中心单位 | 11px / 400 / --app-text-3 |
| 状态标签 | 右上角圆角胶囊（r-pill + accent-3），如"一般故障" |
| 描述行 | 卡片标题（小字） + 副标题（灰色小字） + 时间戳 |

### 12.3 BigKpi（大数字 KPI）

| 项 | 规格 |
|---|---|
| 数字 | 22px / 700 / --app-text-1 |
| 单位 | 11px / 400 / --app-text-3，与数字同行紧贴 |
| 标题 | 11px / 400 / --app-text-3，卡片顶部 |
| 副值 | 11px / 400 / --app-text-3（可选，如"6.83 / 31.91 GB"） |
| 底部进度条 | 高 2px，宽 100%，颜色按值色阶（≥80 绿 / 60-79 橙 / <60 红） |
| 卡片 | 玻璃卡，圆角 r-md |

### 12.4 ServerCard（服务器信息玻璃卡）

| 项 | 规格 |
|---|---|
| 整卡 | 玻璃卡，圆角 r-md |
| 字段 | 标题 11px / 400 / --app-text-3 + 内容 14px / 600 / --app-text-1 |
| 行高 | 28px |
| 行分隔 | 1px `rgba(255,255,255,.05)` |
| 字段对齐 | 标题左 / 内容右 |
| 强调字段 | 主标题 16px / 700（如"主机名 ACE-EPDM"） |

## 13. 视觉验收清单（必须项，不通过不发版）

- [ ] 375×812 无横向溢出（`document.documentElement.scrollWidth ≤ 375`）
- [ ] 底部 TabBar 5 项 sticky 底部，含 iPhone safe-area 适配
- [ ] TabBar 中间项（如有）凸起 56×56
- [ ] 9 宫格图标彩色，圆角玻璃卡质感，accent 映射正确
- [ ] 健康度圆环数字 + 状态标签可读，分数色阶生效
- [ ] BigKpi 数字大字 + 单位小字节奏正确
- [ ] ServerCard 字段对齐、行分隔清晰
- [ ] 玻璃背景模糊效果生效（`backdrop-filter` 真实应用）
- [ ] 6 套皮肤切换无破版（深蓝/紫金/墨绿/冰蓝/暖阳浅/清新浅各 1 张截图过）
- [ ] 字体加载无 FOIT/FOUT
- [ ] 整体配色与 EPDM H5 同质感（深色玻璃主推套需达到 EPDM 同档；浅色套允许质感降低但不可"糊弄"）

---

## 14. 与桌面端的关系

**桌面端**（`> 768px`）维持 v1.1.0 风格不动（侧栏 + 桌面 KPI/表格）。本规范仅约束 H5（≤768）。

如未来需要桌面同步升级（双端统一玻璃风），再开 v1.3.0；token 与组件代码必须能在桌面与 H5 复用，**不在本规范约束范围内**。
