# 设计规范（Design Spec）

> web-console-starter · 视觉/组件的**具体规格**。所有数值均为真实生效值，组件与页面样式**只引用本文的 CSS 变量**，禁止在组件里写死颜色。
> 配套阅读：`docs/换肤指南.md`（token 机制与新增皮肤）、`docs/H5移动端开发约束与指导.md`（手机 H5：断点/触控/页面形态）、`frontend/src/style.base.css`（基础层）、`frontend/src/themes/*.css`（4 套皮肤定义）。

---

## 1. 设计 token 契约（唯一取色入口）

所有颜色都来自 CSS 变量，任何组件/布局**不得硬编码**颜色（尤其禁止白色 `rgba(255,255,255,x)` 直写——浅色皮肤会破版）。契约分三类：

| 类别 | 变量 | 含义 |
|---|---|---|
| 模式 | `--app-mode` | `dark` / `light`，决定 Element Plus 是否挂 `dark` class |
| 背景/面板 | `--bg-0` / `--bg-1` | 页面底/渐变次底色 |
| | `--panel` / `--panel-bd` | 卡片背景（半透明）与描边 |
| | `--panel-solid` | 卡片**不透明**背景（图表 tooltip / 下拉等需要不透明场景） |
| | `--side-bg` / `--top-bg` | 侧栏 / 顶栏背景 |
| 文字 | `--txt` / `--txt-dim` / `--txt-strong` | 常规 / 次要 / 强调文字 |
| 品牌/强调 | `--accent` / `--accent2` | 主强调色与渐变的第二色 |
| | `--logo-fg` / `--btn-fg` | logo 方块文字色 / 主按钮文字色（`--btn-fg` 必须与 accent 保证对比度） |
| 组件态 | `--menu-active-bg` / `--menu-active-txt` | 侧栏菜单激活态 |
| | `--hover-bg` | 通用 hover 底色 |
| | `--input-bg` / `--input-bd` | 输入框 |
| | `--line` | 分隔线 / 描边弱化 |
| | `--track` | 进度轨道（环形图底环、进度条轨道） |
| 图表色盘 | `--chart-1` … `--chart-10` | ECharts 系列色（顺序取用） |

**生产规范**：新增颜色一律先加 token → 皮肤 css 全部补齐 → 组件引用 `var(--token)`。派生色用 `color-mix(in srgb, var(--accent) 35%, transparent)` 之类，不要另造绝对值。

## 2. 预置 4 套皮肤（主色 / 底色 / 适用）

| 皮肤 | 风格 | 主色 accent | accent2 | 背景 | 模式 | 适用 |
|---|---|---|---|---|---|---|
| `deep-blue`（默认） | 深蓝玻璃 | `#22d3ee` | `#a78bfa` | `#0a1124` 渐变 | dark | 运维/监控/中台 |
| `light-pro` | 浅色专业 | `#185FA5` | `#2563eb` | 白+浅灰 | light | 办公/信息管理 |
| `emerald-dark` | 墨绿玻璃 | `#34d399` | `#2dd4bf` | `#06281e` | dark | 制造/生产 |
| `royal-purple` | 紫金玻璃 | `#a78bfa` | `#fbbf24` | `#1a1040` | dark | 门户/展示 |

深色玻璃共性：卡片 `backdrop-filter: blur()` + 半透明底 + 1px 亮描边；浅色皮肤关闭玻璃、用实底浅灰阴影。

## 3. 尺寸 / 间距 / 圆角 / 阴影

| 项 | 值 | 备注 |
|---|---|---|
| 侧栏宽 | 220px（折叠 64px 可另配） | `Layout.vue` 变量 |
| 顶栏高 | 56px | 含标题/账号/皮肤预览 |
| 页面内边距 | 20px（面板网格 gutter 16px） | |
| 卡片圆角 | 12px | `PanelCard` |
| 按钮/输入框圆角 | 6px（EP 默认近值） | 跟随 Element Plus |
| 主按钮 | `linear-gradient(135deg, var(--accent), var(--accent2))`，文字 `var(--btn-fg)` | `style.base.css` |
| hover 提亮 | `filter: brightness(1.08)` | 通用 |
| 卡片阴影 | 深色：0 透明/发光弱化；浅色：`0 4px 16px rgba(15,40,80,.08)` | 由皮肤变量派生 |
| 字号阶梯 | 12(次要)/13(正文)/15(卡片标题)/20(页标题)/28(KPI 数值) | |

## 4. 组件规格

- **PanelCard**：左上 3px accent→accent2 渐变竖条 + 标题 + 右上"更多"插槽；body 无内边距场景用 `body` 具名插槽自行控制。
- **BaseChart**：统一 `echarts.init(el, 'app')`（主题由 `app.theme.js` 按当前皮肤 CSS 变量注册）；必须监听 `ResizeObserver`，销毁时 `dispose`（防泄漏）。
- **KpiRing**：环形色取传入值，缺省读 `var(--accent)`；轨道取 `var(--track)`；中心数值粗体 + `--txt-strong`。
- **表格**：Element Plus `el-table`，暗色下依赖 EP dark class 自动翻转，行 hover 用 `--hover-bg` 覆盖。
- **状态标签**：绿=正常/成功、红=异常/告警、琥珀=警告/待处理（语义色请用主题内 `--chart-*` 或组件内 tint，勿硬编码品牌色）。

## 5. ECharts 色盘

`app.theme.js` 运行时从 CSS 变量读取 `--chart-1..10` 并注册为 `'app'` 主题。图表**不要**自建 series color 数组，直接沿用主题：多系列按 `chart-1..N` 顺序取色；饼图用前 N 个。换肤时图表随页面自动更新（重渲染或整页重载）。

色盘建议（以 deep-blue 为例）：`#22d3ee #a78bfa #34d399 #fbbf24 #f472b6 #60a5fa #fb7185 #4ade80 #c084fc #facc15`。新增皮肤由 `new-skin.ps1` 自动生成协调的 10 色（主色 + 色相旋转 + 明度档位）。

## 6. 模式规则（dark / light）

- `--app-mode: dark|light` 是**唯一**模式来源：`main.js` 启动时读取并给 `<html>` 挂/卸 `dark` class → Element Plus 整体明暗随之切换。
- 组件样式永远写变量，不写"我以为的浅色/深色值"；验收用 4 皮肤全页面截图防破版。

## 7. 布局与页面模板速览

| 页面 | 组成 |
|---|---|
| 登录页 | 全屏 `--bg-0→--bg-1` 渐变 + 玻璃卡片（logo/标题/副标题读 app.config）+ 默认账号提示 |
| 总览 | 状态横幅 + KPI 环形格 + 双线趋势（panel） + 占比饼图 + 事项/服务两栏 |
| 列表 | 工具条（搜索/分类/状态）+ el-table + 分页 + 增删改弹窗 |
| 趋势 | 时间范围(7/30/90) + 全宽多系列折线 + 区间合计柱状 |
| 详情 | 指标网格(8) + 30 日大图 + 明细表 |

> 页面内容一律来自 mock（开发期）或真实 API（联调后），**禁止静态桩**。
