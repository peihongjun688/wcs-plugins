# 兼容与分发（Compatibility & Distribution）

> web-console-starter 的三种形态 + 一套引导层 + 发布门禁。原则：**①开发态目录是唯一真源，②zip / ③Skill 全部由脚本从①生成**，绝不手工维护三份。

---

## 1. 三种形态

| 形态 | 位置 | 用途 | 产生方式 |
|---|---|---|---|
| ① 开发态（唯一真源） | 本模板目录 | 日常开发、反哺迭代 | 手动编辑 |
| ② 发布态 zip | `dist/web-console-starter-vX.Y.Z.zip` | 拷贝到任意机器/任意智能体环境 | `build-dist.ps1`（含内置 SPA，解压即跑） |
| ③ 市场态 Skill | 本包（含自包含 `SKILL.md`） | 上传智能体技能市场 / 解压到任意智能体 skills 目录（Claude / Codex / WorkBuddy / Cursor 等均可） | 由②再打包（包内 `SKILL.md` 为自包含版，不依赖任何本机绝对路径） |

## 2. 一包四入口（智能体无关的引导解法）

模板本体是**纯代码**，任何智能体（Claude / Codex / WorkBuddy / Cursor…）都能读写，无锁定。区别只在"怎么被引导"，四入口覆盖主流：

| 文件 | 谁读 | 作用 |
|---|---|---|
| `README.md` | 人 + 所有 AI | 项目简介、目录、30 秒开始 |
| `AI-GUIDE.md` | ★ 任何智能体 | 完整开发规范：接入步骤/目录职责/5 类页面写法/后端加模块法/校验清单/踩坑表 |
| `CLAUDE.md` | Claude Code（自动加载） | 指路 → AI-GUIDE |
| `AGENTS.md` | Codex（自动加载） | 指路 → AI-GUIDE |
| WorkBuddy | 配套 Skill | 加载后同样按 AI-GUIDE 执行 |

> 新出现的智能体：只要求它先读 `AI-GUIDE.md` 即可。

## 3. 从模板到新系统（命令流）

```powershell
# 1) 初始化：拷贝模板 → 新目录，改名/标题/logo/皮肤/端口，生成 backend/.env
powershell -ExecutionPolicy Bypass -File scripts/init-app.ps1 `
  -AppName my-orders -Title "订单管理系统" -LogoText OD -Skin light-pro -Port 8080 -Install

# 2) 名称一致性复核（五处：app.config/pkg×2/index.html/皮肤css）
powershell -ExecutionPolicy Bypass -File scripts/check-names.ps1 -Path D:\proj\my-orders

# 3) 日常启停
D:\proj\my-orders\scripts\start.bat    # 自动装依赖/缺则构建/起服务/开浏览器
D:\proj\my-orders\scripts\stop.bat
# Linux/macOS：start.sh / stop.sh

# 4) 发布前脱敏（红线）
powershell -ExecutionPolicy Bypass -File scripts/scan-secrets.ps1   # 0 命中才可发布

# 5) 出发布 zip（内部已强制先跑 scan-secrets）
powershell -ExecutionPolicy Bypass -File scripts/build-dist.ps1
```

## 4. 隐私红线（发布前强制）

`scan-secrets.ps1` 递归扫描**内部关键词清单**（产品名/服务器标识/网段 IP/内部路径/用户名等，完整清单见 `scan-secrets.ps1` 头部注释），命中任一即 exit 1、不出包。打包（build-dist）还会剥离：

- `node_modules / .git / dist / logs / data`
- `*.db / backend/.env（真实密钥）/ backend.pid / backend.log`
- vite 临时产物 `vite.config.js.timestamp-*.mjs`

`.env.example` 全占位符（含默认演示账号 admin/admin123 占位，首启请改）。README/LICENSE 无作者与内部信息。

**注意**：`robocopy /XD` 只认「目录名」或「**完整路径**」，`backend\public` 这类相对路径写法无效；改动排除清单时请使用全路径（见 `init-app.ps1`）。

## 5. 演示实例

验收后保留本机演示站（默认 `:5190`，用 init-app 另起的独立实例）：4 皮肤可切换、数据用模板种子、**不涉及任何生产数据**。用完可停（stop.bat），随时可再起。

## 6. 公开发布前置（如对外）

1. `skills-security-check` 安全审计通过；
2. `scan-secrets` 零命中；
3. LICENSE（MIT，无作者）随包；
4. 登录页/页脚去除任何原系统署名。

> 内部团队分发/自有技能市场：随包即可，无需上述外发流程。
